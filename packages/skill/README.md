# @neko-catpital-labs/drafter-skill

Portable `draft-pr` and `split-scope` markdown skills, installable into
Claude Code, Cursor, Codex, or omp.

```bash
npx @neko-catpital-labs/drafter-skill install --tool claude
```

Installs `~/.claude/skills/drafter-draft-pr/` and
`~/.claude/skills/drafter-split-scope/`. Omit `--tool` to install into every
known tool's directory, or pass `--target <dir>` to copy into an arbitrary
directory instead.

See the repo root [`README.md`](../../README.md) for the full picture.
